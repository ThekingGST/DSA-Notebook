# Teacher Mode Interaction Model

For V1, Teacher Mode is accessible via a top-bar segmented toggle (`[ 🎓 Student Mode | 👨‍🏫 Teacher Mode ]`) operating on the same canvas. The mode activates a specialized DSA Toolbox with quick-configure popovers for 1D arrays (preset or comma-separated values), leaving freehand gesture recognition and slash commands for future iterations.

Pointers are manipulated via smooth freehand dragging that reliably snaps to cell centers upon release without jittery snapping during drag. Array cells support in-place double-click editing, and arrays feature `[+]` / `[−]` end-caps for dynamic resizing during live teaching.
